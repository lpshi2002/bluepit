# 차종별 소모품 교체 주기와 가혹 조건

앱(`app/.../agent/Schedule.kt`, `DrivingPattern.kt`)에 넣은 값의 출처와 판단 기준. (2026-10-31)

## 출처와 조사 방법

- 현대차 공식 취급설명서 웹 버전(ownersmanual.hyundai.com, 국문판)의 "정기 점검 주기 > 통상 조건 / 가혹 조건" 표를 차종별로 내려받아 표의 행·열을 그대로 읽었다.
- 주소 형식: `https://ownersmanual.hyundai.com/full_webhelp/{차종코드}/{연식}/ko_KR/` (목차는 `data/tocData.json`)
- 국문판에는 "짧은 거리"의 km 기준이 없다. 8 km 기준과 "10년·150,000 km" 조건은 미국판(`/full_webhelp/NX4/2025/en_US/id3ce613a50f9.html`)에서 가져왔다.
- 표에 "상태에 따라 수시 점검"처럼 숫자가 없는 항목은 앱에 넣지 않았다.

## 가혹 조건과 앱의 판단

국문 설명서의 가혹 조건 12가지와, 앱이 그중 무엇을 차량 데이터로 판단하는지.

| 번호 | 조건 | 앱 판단 |
|---|---|---|
| 1 | 짧은 거리 반복 주행 | **자동**: 최근 30일 중 8 km 미만 주행의 지수 가중 점수가 0.5 이상 (8 km는 미국판 기준) |
| 3·4·9 | 과다한 공회전, 교통 체증 구역, 잦은 정지·출발 | 공회전은 직접 선택. 체증은 평균 20 km/h 미만(시연 시 정체 비율 0.5 이상), 정지·출발은 분당 브레이크 1.5회 이상에 해당하는 주행의 지수 가중 점수가 0.5 이상일 때 적용 |
| 2, 5, 6, 7, 8, 10, 11, 12 | 먼지, 험로, 산길, 택시·상용, 고속·급가감속, 소금·한랭, 견인·캠핑, 비추천 오일 | 사용자가 설정에서 직접 고른다 |
| (미국판) | 10년 또는 150,000 km 이상 | **자동**: 누적 주행거리 또는 차대번호 연식 |

- 조건별 유효 주행이 10회 이상일 때 최근 주행에 0.15의 가중치를 준다. 확정 전에는 짧은 거리 0.35, 체증 0.30, 공회전 0.20, 정지·출발 0.15를 적용한 지수로 엔진오일 주행거리 주기만 앞당긴다. 이 가중치와 보간은 앱이 정한 값이다.
- 엔진오일은 12가지 조건 모두에 가혹 조건 주기를 쓴다.
- 짧은 거리와 저속 판단에는 Vehicle SDK의 "이번 주행 거리(m)·시간(분)"을 쓴다. 주행이 10회 이상 모여야 판단한다.
- 한랭 지역 기준(16 km)은 외기 온도를 SDK로 읽을 수 없어 쓰지 않았다.

## 차량 데이터로 차종을 알아내는 범위

| 데이터 | 에뮬레이터 결과 (2026-10-31) | 쓰는 곳 |
|---|---|---|
| 연료 잔량 / 배터리 충전량 | 연료 없음, 배터리 있음 → 전기차로 감지 | 처음 실행 시 기본 차종 (전기차면 아이오닉 5, 아니면 투싼 1.6T) |
| 차대번호(VIN) | `"invalid"` 문자열 | 10번째 자리로 연식 (ISO 3779). 에뮬레이터에서는 연식을 알 수 없다 |
| 이번 주행 거리·시간 | 지원하지 않음 (`ERROR_NOT_SUPPORTED_PROPERTY`) | 짧은 주행·저속 판단. 에뮬레이터에서는 시연 버튼으로 주행을 만든다 |

차종과 엔진은 차대번호만으로 정확히 알 수 없어(현대차 차대번호 해석표 비공개), 사용자가 설정에서 고른다. 감지한 동력계와 다른 차종을 고르면 화면에 표시한다.
