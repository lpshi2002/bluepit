# Pleos 공개 API로 읽을 수 있는 데이터

현대자동차그룹 차량용 앱 개발 공모전(2026) 기준. 값을 읽어 오는 것만 정리했다. (2026-10-26)

> SDK에 있다는 것만 확인했고, 에뮬레이터에서 실제 값이 나오는지는 아직 모른다. 차종에 따라 없는 항목도 있다. 예를 들어 전기차와 내연기관차는 다르고, 스마트 글래스는 일부 차에만 있다.

## 차량

**주행**
- 조향각
- 방향지시등
- 브레이크 페달 밟음 여부
- 주행 모드
- 크루즈 켜짐 여부, 설정 속도

**주행 기록**
- 누적 주행거리
- 주행 가능 거리
- 이번 주행 거리·시간
- 누적 주행 거리·시간
- 주유 후 거리·시간

**연료 (내연기관·하이브리드)**
- 연료 잔량(%)
- 연비

**배터리 (전기차)**
- 배터리 잔량, 충전 상태, 용량
- 전비
- 충전 중 여부, 충전 전류 한도, 충전구 열림

**시트 (좌석별)**
- 사람이 앉았는지
- 안전벨트 착용
- 등받이 각도, 앞뒤·높이·기울기·깊이
- 헤드레스트, 허리 지지
- 열선·통풍 단계

**공조**
- 실내 현재 온도
- 설정 온도, 켜짐, 에어컨
- 바람 세기·방향
- 내기순환, 공기청정, 성에 제거, 자동 모드

**조명**
- 앰비언트 조명 켜짐·밝기·색 (좌석별)
- 실내등, 독서등 (독서등은 좌석별)
- 상향·하향등, 안개등, 미등

**창문·문**
- 창문 열림 정도, 창문 잠금
- 블라인드 위치
- 스마트 글래스 상태·단계
- 문 열림, 문 잠금, 글러브박스 잠금

**안전**
- 안전벨트 미착용 경고
- 에어백 작동 여부, 에어백 전개
- 워셔액 부족
- 엔진오일·브레이크액·변속기오일 양 (부족·정상·많음 단계만. 오일이 얼마나 낡았는지는 알 수 없다)
- 타이어: 공기압 "위험 수준 기준값"만 있다. 현재 공기압이나 부족 경고는 읽을 수 없다 (2026-11-02 SDK 문서 재확인)

**기타**
- 와이퍼 상태
- 스티어링 열선, 사이드미러 열선
- 하이패스 안내 음량
- 차대번호

## 내비게이션

**위치·장소**
- 현재 위치와 주소
- 목적지, 경유지
- 최근 목적지
- 즐겨찾기 (집·회사·충전소)

**경로**
- 남은 거리, 도착 예정 시간
- 예상 에너지 소모, 도착 시 예상 배터리
- 경로 좌표, 구간별 교통 상황

**실시간 안내**
- 다음 회전 안내 (방향·거리)
- 현재 도로 제한속도

**주의 구간 (23가지, 남은 거리 포함)**
- 과속방지턱, 스쿨존, 사고 다발, 철도 건널목
- 안개, 낙석, 급경사 내리막, 야생동물, 좁은 길
- 공사, 미끄러운 길, 도로 파손, 역주행
- 버스전용차로·끼어들기 단속 등

**단속 카메라**
- 종류, 남은 거리, 제한속도, 구간 평균속도

**교통**
- 정체 구간의 도로명·평균 속도·정체 정도
- 사고·공사·재해 정보

**이벤트 알림**
- 안내 시작, 경로 계산 완료, 안내 취소
- 도착, 경유지 도착
- 재탐색 완료, 목적지·경유지 변경

**상태**
- 대기 중 / 목적지 없이 주행 중 / 경로 안내 중

## 위치

- 위도, 경도, 고도, 진행 방향, 정확도, 시각
- 지정한 지점 반경에 들어가고 나갈 때 알림

## AI

- 음성인식 결과 텍스트, 말소리 크기, 말이 끝난 시점
- LLM 답변 (텍스트·이미지 입력)

## 못 쓰는 데이터

- 차량 속도, 가속도
- 브레이크 세기
- 심박수·체온 같은 생체 데이터
- 운전자 졸음 경고
- 차 안 카메라 영상
- 경고등 정보
- 타이어 공기압 수치와 부족 경고
- 바깥 온도 (실내 현재 온도만 있다)
- 경로 전체 좌표 (경유지·목적지 좌표와, 특정 지점까지의 거리·도착 예정 시간만 있다)
- 기어 상태 (애매함)
- 장소 검색
- 오디오 볼륨
- 화자 인식, 좌석별 음성 분리
