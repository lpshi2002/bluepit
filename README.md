# 피트스톱 (Pitstop)

차가 운전 습관을 보고 소모품 교체 시점을 미리 계산해, 가던 길에 들를 수 있는 블루핸즈와 시간을 먼저 골라 묻고, "응" 한마디로 승인하면 내비게이션 경유지까지 넣어 주는 차량 정비 에이전트입니다.

현재 Android 시연에서는 버튼으로 답한다. 앱이 정비소·시각·항목을 다시 보여 주면 **확정**을 누른다. 일반 정비소는 앱에 계획을 저장한 뒤 공식 채널에서 접수하고, 제휴를 가정한 오늘 퇴근길 예약은 내비에 경유지 추가를 요청한다.

## 설치와 실행

시험 환경은 Pleos Connect v2.1 에뮬레이터, Android 14, 가로 2560 × 세로 1440 px이다. 에뮬레이터를 부팅한다. 설치 파일은 [심사용 release APK](apk/pitstop_피트스톱_release.apk)다. 저장소 루트에서 실행한다.

```sh
adb install -r apk/pitstop_피트스톱_release.apk
adb shell am start -n app.pitstop/.MainActivity
```

소스 빌드에는 JDK 17과 Android SDK Platform 35가 필요하다. Android Studio에서 app 폴더를 열거나 다음 명령을 실행한다. Gradle이 app/settings.gradle.kts의 Pleos Maven 저장소에서 Vehicle SDK 2.3.2와 NaviHelper 3.0.5를 내려받는다.

```sh
cd app
./gradlew testDebugUnitTest assembleRelease
```

## 심사 시연

1. 정차 상태에서 앱을 연다. 마지막 정비 시점을 입력하거나 **별도 시연 시작**을 선택한다.
2. **시동 걸 때 제안**으로 월요일 아침의 투싼 1.6 터보를 불러온다. 엔진오일 교체까지 25일이 남은 이유와 08:30 출근길 후보를 확인한다.
3. **예약하기 → 확정**으로 계획을 저장한다. 10초 안에는 **되돌리기**를 누를 수 있다.
4. **시동 걸 때 제안 → 제휴 가정 켜기 → 오일 양 부족 신호**로 당일 18:10 점검 제안을 확인한다. 승인하면 첫 경유지 추가를 요청한다.

19개 차종·엔진의 설명서 주기, 가혹도 계산, 제휴·일반 정비소 시간대, 다음 예약 제안과 취소를 담았다. 정비소와 빈 시간은 샘플이다. 실제 예약 연동, 음성 인식과 실차 시동 자동 실행은 향후 개발 범위다. 시험 이미지에서 지원하지 않는 주행·오일 양 신호는 별도 시연 기록으로 재현한다. 화면별 조작과 검증 범위는 [Android 앱 안내](app/README.md)에 있다.

## 웹 시뮬레이터

저장소를 내려받고 web/index.html을 브라우저로 연다. 별도 서버 없이 가상 주행을 추가하고 교체 주기와 예약 후보를 비교할 수 있다. 웹과 Android는 각각 데이터를 저장한다.
